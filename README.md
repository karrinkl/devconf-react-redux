# DEVCONF 2026 - лендинг IT-конференции на React с Redux Toolkit

Лабораторная работа № 22. Внедрение глобального управления состоянием
в React-приложение.

Вариант 2: лендинг IT-конференции. Проект продолжает работу № 19:
компоненты, вёрстка и ассеты перенесены оттуда без изменений, добавлено
централизованное хранилище для списка избранных спикеров.

## Стек

- React 18, функциональные компоненты и хуки
- Redux Toolkit 2 и React-Redux 9 для глобального состояния
- Vite 5 как сборщик и dev-сервер
- CSS Modules, PropTypes

## Требования

- Node.js версии 18 или новее
- npm версии 9 или новее

## Запуск

```bash
git clone <адрес репозитория>
cd devconf-react-redux
npm install
npm run dev
```

Vite выведет в терминал адрес локального сервера, по умолчанию
http://localhost:5173.

Если проект разворачивается поверх копии ЛР № 19, недостающие пакеты
ставятся командой:

```bash
npm install @reduxjs/toolkit react-redux
```

## Остальные команды

```bash
npm run build     # production-сборка в каталог dist
npm run preview   # локальный просмотр собранной версии
```

## Структура хранилища

```
src/store/
├── favoritesSlice.js   срез состояния: initialState, редюсеры, селекторы
└── index.js            configureStore, сборка корневого редюсера
```

Хранилище отделено от интерфейса: в каталоге `src/store` нет ни одного
JSX-файла, а компоненты не знают о внутренней форме состояния, потому что
обращаются к нему только через селекторы.

### Срез favorites

| Элемент | Значение |
|---|---|
| Имя среза | `favorites` |
| Начальное состояние | `{ ids: [] }` |
| Действие `toggleFavorite(id)` | Добавляет идентификатор в массив или убирает его оттуда |
| Действие `clearFavorites()` | Очищает список целиком |
| Селектор `selectFavoriteIds` | Возвращает массив идентификаторов |
| Селектор `selectFavoritesCount` | Возвращает число избранных |
| Селектор `selectIsFavorite(id)` | Возвращает признак «спикер в избранном» |

В хранилище лежат только идентификаторы. Данные спикеров остаются
в `src/data/content.js`, поэтому два источника истины не расходятся.

## Подключённые компоненты

| Компонент | Что читает из store | Что отправляет в store |
|---|---|---|
| `SpeakerCard` | `selectIsFavorite(id)` через `useSelector` | `toggleFavorite(id)` через `useDispatch` |
| `Favorites` | `selectFavoritesCount`, `selectFavoriteIds` | `clearFavorites()` |

Компоненты не обмениваются данными напрямую и не связаны общим родителем
через props: карточка ничего не знает о панели избранного, панель ничего
не знает о карточках. Единственный канал связи между ними - хранилище.

## Что можно проверить в интерфейсе

1. Клик по звёздочке на карточке закрашивает её и увеличивает счётчик
   в панели «Избранное» над списком спикеров.
2. Повторный клик убирает спикера из избранного, счётчик уменьшается.
3. Кнопка «Очистить» в панели снимает отметки сразу со всех карточек,
   хотя панель не обращается к ним напрямую.
4. При установленном расширении Redux DevTools во вкладке видно каждое
   отправленное действие и состояние хранилища до и после него.

## Связь с предыдущими работами

Макеты и графические ассеты взяты из ЛР № 17, структура компонентов
и токены дизайн-системы - из ЛР № 19. Локальное состояние, не относящееся
к избранному, осталось в компонентах: раскрытие блока FAQ и поля формы
регистрации по-прежнему живут в `useState`, поскольку эти данные нужны
только внутри своего компонента.
